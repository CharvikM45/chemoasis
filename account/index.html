    What shaped these suggestions

      How suggestions work

      A small learning model gives each game a fit score from your questionnaire answers. It starts from weights that link each answer to the games that practice it (for example, “trouble finding words” and Story Echo). Then it learns from you: each time you play a game or choose “Not for me,” it adjusts your own weights so suggestions follow what you actually choose. Community topics count a little, as popularity only.

      The score shows how well a game fits your answers and choices. It isn't a chance that a game will help a medical condition, and none of these games have been clinically tested. This is not a health result.
